# 🎮 보드 동물 놀이터

보드 타는 귀여운 동물들의 미니게임 모음 (도트 그래픽, 브라우저에서 바로 실행, 모바일 터치 지원)

- 🪙 **코인런** — 달리고 점프하고 코인 모으는 2D 플랫포머. 레일 그라인드, 킥커, 공중 묘기, 적 밟기, 4가지 배경(해변/숲/설원/밤도시)
- 🏁 **레일 레이스** — 5개 레일을 타고 위로 달려 결승선까지. 레일 이동·점프·부스트 패드, 라이벌 동물 3마리

동물 5종(고양이·강아지·펭귄·판다·카피바라)과 보드 5종(스케이트·롱보드·크루저·서핑·스노우)은 모든 게임에서 공유되고, 코인으로 동물을 해금해요.
진행 상황은 브라우저(localStorage)에 저장돼요.


## 🛞 매뉴얼 버티기
화면을 꾹 누르면 앞으로, 떼면 뒤로 쏠려요. 초록 구간에서 오래 버티기! 아스팔트 → 맞바람 → 점자블록 → 자갈길로 갈수록 흔들림이 커지고, 넘어지면 웃긴 칭호와 기록을 공유할 수 있어요.
